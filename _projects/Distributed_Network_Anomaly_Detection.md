    - Designed and implemented a distributed anomaly detection system based on a multi-agent architecture for monitoring network and system resources.
    - Developed local and central agents using JADE to detect, correlate, and analyze CPU overload, bandwidth saturation, and distributed attack patterns.
    - Built a network simulation environment with Mininet and Open vSwitch to emulate realistic network topologies and traffic scenarios.
    - Developed alert aggregation and correlation mechanisms enabling centralized detection of anomalies affecting multiple network nodes.
    - Integrated MySQL for persistent storage of alerts and monitoring data, supporting historical analysis and reporting.
    - Configured Grafana dashboards to visualize system metrics, network performance, and anomaly events in real time.
    - Validated detection capabilities through stress-testing and traffic-generation tools including iperf3, htop, and iftop.
    - Delivered a distributed multi-agent monitoring platform integrating Mininet, JADE, Python, MySQL, and Grafana to detect, correlate, and visualize network and system anomalies across simulated environments.
